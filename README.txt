העלאה ל-GitHub Pages
1. צרו מאגר Public ב-github.com.
2. Add file > Upload files: גררו את כל הקבצים והתיקיות מהתיקייה הזו.
3. Settings > Pages > Deploy from a branch > main / (root) > Save.
4. ב-script.js ערכו את בלוק CONFIG (OWNER, REPO, שם, אימייל).
5. ב-index.html החליפו USER ו-REPO בכתובות, ואת הטקסטים.
6. הוסיפו צילומי מסך לתיקייה assets/shots, ותמונת og-image.png בגודל 1200x630.
7. צרו Release עם קובץ ה-APK כדי שאזור ההורדה יתמלא.
